# DevTask — Proyecto de primer parcial

Proyecto de Programación Móvil de Kevin Jahir Coronel Gaona, Universidad Técnica de Machala.

Esta rama inicial registra el objetivo del proyecto. La implementación Angular con API Node.js, SQLite, especificaciones y pipeline se desarrolla en `feat/gestion-tareas` y se propone mediante Pull Request.

## Objetivo
Crear un tablero de tareas con responsables, prioridades y estados, aplicar especificaciones verificables, control de versiones y automatización de pruebas y compilación.

La revisión del segundo integrante debe realizarse desde su cuenta real. Los documentos distinguen la evidencia local de las acciones realizadas en GitHub.
