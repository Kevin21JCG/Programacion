# Constitución de DevTask
1. Las especificaciones y los criterios verificables preceden a la implementación.
2. Cada requisito tiene una prueba o una comprobación manual definida.
3. main debe compilar. Los cambios se integran por PR pequeño y revisión de otro integrante.
4. Ningún dato de entrada se considera confiable. Validar en servidor y parametrizar SQL.
5. Asistencia de IA con revisión humana. Registrar el prompt y las correcciones realizadas.
6. Diferenciar evidencia real, demostración local y actividad pendiente.
Archivo de principios preparado manualmente. No acredita ejecución de GitHub Spec Kit.
